Stylish terminal based role playing game:
- completely self-made `ASCII-Art` UI (You can´t tell me this isn´t cool as)
- procedurally generated dungeons to explore
- `fighting`, `shop` and `inventory` mechanics
- animations
- multi-`language` support
- customizable `theming`

`AI-based` dynamic storytelling based on the players choices, their inventory, history level etc...

(requires an OpenAi api key)
